迁移在独立服务中执行。请在源端和目标端分别准备。

启动迁移模式

  1. 停止业务写入

    停止 HTTP、MCP 与独立后台任务，完成必要落盘。导入需要空目标。

  2. 配置密钥并启动服务

    配置 auth.root_api_key 或设置 OGMEM_MIGRATION_API_KEY。

    ogmem migration --config /path/ogmem.yaml --workspace /path/migration-work --maintenance-confirmed

  3. 打开迁移页面

    默认地址为 http://127.0.0.1:8091。远端部署可通过 SSH 端口转发访问。

完成校验后

停止迁移服务，再启动业务服务。
